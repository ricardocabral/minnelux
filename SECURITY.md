# Security policy

Security fixes target the `main` branch.

Use [GitHub private vulnerability reporting](https://github.com/ricardocabral/minnelux/security/advisories/new) when available. If the form is unavailable, contact a maintainer through a private channel. Keep vulnerability details out of public issues and pull requests.

Include the affected commit or version, the impact, and steps to reproduce with synthetic data. Redact credentials and private media or metadata. Give maintainers time to investigate and coordinate disclosure.
